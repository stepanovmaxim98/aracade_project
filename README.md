# 🕹️ Платформер на Arcade

## 📌 Описание

Это 2D платформер, разработанный на Python с использованием библиотеки **Arcade**.

Игрок управляет персонажем, который должен собрать **15 монет** за ограниченное время — **2 минуты**.

---

## 🎯 Цель игры

- Собрать **15 монет**
- Уложиться в **2 минуты**
- Избегать бомб

---

## ⏱️ Система времени

- Игра начинается с таймера **02:00**
- Время отображается в правом верхнем углу в формате: mm:ss

Игра завершается победой, если игрок собрал **15 монет**.



## 🏆 Победа

После победы:

- отображается сообщение **"ПОЗДРАВЛЯЮ!"**
- игра останавливается

---

## 💾 Сохранение результатов

После победы результат автоматически сохраняется в файл: results.csv

## 🎮 Управление

- `A / ←` — движение влево
- `D / →` — движение вправо
- `W / ↑` — прыжок

---

## Попробовать игру

#### 📦 Установка зависимостей

```bash
pip install -r requirements.txt
```

#### Запуск игры

```bash
python main.py
```
